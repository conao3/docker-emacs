* docker-emacs

Run Emacs in Docker containers with ease.

This project provides ready-to-use Docker images for various Emacs versions, making it simple to test packages across different Emacs releases or run Emacs in isolated environments.

** Image Variants

- *Standard images* (~500MB) - Contains runtime dependencies for running Emacs
- *Dev images* (~1400MB) - Includes developer tools like [[https://cask.readthedocs.io][Cask]], git, and Python. Emacs source is available at ~/opt/emacs~ for custom builds
- *Alpine images* (~200MB) - Lightweight images based on [[https://alpinelinux.org][Alpine Linux]]

* Getting Started

** Prerequisites

Install Docker on your system. See the [[https://docs.docker.com/get-docker/][official Docker documentation]] for instructions.

** Console Mode

#+begin_src bash
docker run -it --rm conao3/emacs
#+end_src

** GUI Mode

#+begin_src bash
xhost +local:root  # Note: This has security implications
docker run -it --rm -e DISPLAY -v /tmp/.X11-unix:/tmp/.X11-unix conao3/emacs
#+end_src

* Contributing

Pull requests are welcome.

The development workflow:

1. Modify files in the ~/resources~ directory
2. Run ~lein run -- gen~ to generate Dockerfiles
3. Run ~lein run -- build~ to build Docker images
